NetPredict exposes asynchronous endpoints built on **FastAPI**, with strict Pydantic v2 data validation schemas.

---

### Ingestion & Telemetry Endpoints

<ApiReference method="POST" path="/api/v1/telemetry/ingest">
  <ApiParam name="source" type="string" required={true}>
    Telemetry collector identifier (e.g. `snmp_poller`, `int_agent`).
  </ApiParam>
  <ApiParam name="records" type="array" required={true}>
    Array of raw telemetry points containing `device_id`, `interface_id`, `queue_occupancy_pct`, `rtt_ms`, `interface_loss_pct`, `cpu_util_pct`.
  </ApiParam>
</ApiReference>

<ApiReference method="GET" path="/api/v1/telemetry/latest">
  <ApiParam name="device_id" type="string" required={false}>
    Target router device ID (default: `core-router-alpha`).
  </ApiParam>
  <ApiParam name="interface_id" type="string" required={false}>
    Target interface (default: `xe-0/0/1`).
  </ApiParam>
</ApiReference>

---

### Multi-Horizon Prediction & Anomaly Endpoints

<ApiReference method="GET" path="/api/v1/predict/horizons">
  <ApiParam name="device_id" type="string" required={false}>
    Target router identifier.
  </ApiParam>
  <ApiParam name="interface_id" type="string" required={false}>
    Target interface port.
  </ApiParam>
</ApiReference>

Returns calibrated failure probabilities and 90% conformal intervals across $T+5m, T+15m, T+30m$, alongside the decoupled real-time anomaly status.

---

### TreeSHAP Explainability Endpoints

<ApiReference method="GET" path="/api/v1/explain/latest">
  <ApiParam name="device_id" type="string" required={false}>
    Target router identifier.
  </ApiParam>
</ApiReference>

Computes exact additive Shapley values $\phi_j$ and synthesized natural language root-cause diagnostics.

---

### Counterfactual Simulation Endpoints

<ApiReference method="POST" path="/api/v1/simulate">
  <ApiParam name="reroute_traffic_pct" type="float" required={true}>
    Percentage of ingress traffic to divert ($0.0 - 100.0\%$).
  </ApiParam>
  <ApiParam name="ingress_rate_limit_pct" type="float" required={true}>
    Policer rate reduction percentage ($0.0 - 90.0\%$).
  </ApiParam>
  <ApiParam name="buffer_expansion_factor" type="float" required={true}>
    Buffer multiplier factor ($1.0 - 3.0\times$).
  </ApiParam>
  <ApiParam name="enable_priority_queuing" type="boolean" required={true}>
    Toggle strict WFQ priority queuing.
  </ApiParam>
</ApiReference>
