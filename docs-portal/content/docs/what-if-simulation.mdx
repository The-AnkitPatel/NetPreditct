The **Counterfactual What-If Simulation Engine** allows network operators and automated orchestrators to evaluate candidate mitigation strategies on digital twin feature vectors before touching production routers.

---

### Candidate Operator Interventions

Operators can dynamically perturb 4 primary network control parameters in the scenario lab:

1. **Traffic Diversion (0% to 100%)**:
   * Simulates adjusting BGP local-preference or OSPF link weights to route a percentage of ingress flows over redundant paths.
   * *Feature Impact*: Directly scales down `util_mean` and `bytes_sec`.

2. **Ingress Rate Limiting (0% to 90%)**:
   * Simulates deploying a token-bucket policer to clamp aggressive ingress microbursts.
   * *Feature Impact*: Dampens queue occupancy spikes and reduces packet discard cliffs.

3. **Burst Queue Buffer Expansion (1.0x to 3.0x)**:
   * Simulates dynamically resizing switch port buffers to absorb transient TCP bursts.
   * *Feature Impact*: Normalizes `queue_stress_index` by dividing occupancy by the buffer multiplier.


4. **Strict Priority Queuing (WFQ QoS Mode)**:
   * Toggles low-latency bypass queuing for VoIP and telemetry packets.
   * *Feature Impact*: Lowers estimated RTT and prevents head-of-line blocking.

---

### Counterfactual Feature Transformation Mechanics

Given the current feature vector `X0`, the simulator constructs counterfactual vector `X*` using physical network constraints:

```text
X*_util  = X0_util  * (1 - reroute_pct / 100) * (1 - rate_limit_pct / 100)
X*_queue = (X0_queue / buffer_factor) * (1 - reroute_pct / 100)
```

The counterfactual vector `X*` is then evaluated through the calibrated LightGBM model:

```text
R_hat*     = Model(X*)
Delta_Risk = ((R_hat* - R0) / R0) * 100%
```

### Verdict Classification

* **OPTIMAL**: Risk reduced by $> 75\%$ with zero collateral impact on RTT.
* **EFFECTIVE**: Risk reduced by $40\% - 75\%$. Recommended for immediate rollout.
* **MARGINAL**: Risk reduced by $10\% - 40\%$. Secondary intervention recommended.
* **STABLE**: Risk change within $\pm 10\%$. Baseline network is already nominal.
* **INEFFECTIVE**: Intervention fails to lower predictive risk (e.g. expanding buffer during upstream BGP flap).
