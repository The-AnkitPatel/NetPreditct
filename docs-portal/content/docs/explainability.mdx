### Additive Shapley Formulations

TreeSHAP decomposes a prediction `f(x)` into additive contributions from each telemetry feature:

`f(x) = phi_0 + sum(phi_j(x))`

Where:
* `phi_0 = E[f(x)]` is the expected baseline prediction across the training distribution.
* `phi_j(x)` is the Shapley value for feature `j`, representing its exact attribution to the shift in failure risk.
* **Efficiency Guarantee**: NetPredict implements the Lundberg et al. polynomial-time algorithm `O(T * L * D^2)` rather than exponential model-agnostic KernelSHAP `O(2^M)`, enabling sub-2ms real-time attribution on live 1-minute telemetry ticks.
