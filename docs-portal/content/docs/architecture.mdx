NetPredict is structured around a strict **Hexagonal Architecture (Ports & Adapters)**. This guarantees that mathematical models, temporal feature calculators, and domain state machines remain entirely decoupled from external network telemetry protocols and HTTP delivery transports.

### Concurrency & Performance Characteristics

* **Lock Contention**: The sliding window employs an atomic lock around window updates, with average lock retention time under 0.04 ms.
* **Data Locality**: Telemetry points are held contiguously in memory, avoiding garbage collection overheads.
* **Vectorized Processing**: Feature transformations leverage NumPy vectorization to extract 18 rolling features in under 0.8 ms.
